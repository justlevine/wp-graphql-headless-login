# How to Contribute as an Agent

This document provides guidance for autonomous agents contributing to this repository.

## 1. Prime Directive

Your primary directive is to adhere to the principles and instructions outlined in the **Agent Constitution**.

**All operational instructions, architectural details, coding conventions, and escalation protocols are defined in the `.agent_docs/` directory.**

- **Start Here:** Begin any series of tasks by consulting the constitution at `/.agent_docs/AGENT_CONSTITUTION.md`.
- **Source of Truth:** The `.agent_docs/` directory is the single source of truth for all agentic work.
